# The Climb

A daily football trivia game. Seven prompts, 30 seconds each, and the rarer your answer the more points you score. Your points climb the football pyramid, from Sunday League to the European Cup Final.

## Files

- `index.html`: the page
- `css/style.css`: the look
- `js/questions.js`: the prompts, answers and rarity points (edit this to add questions)
- `js/scenes.js`: the five pitch and stadium backdrops
- `js/game.js`: timer, answer matching, scoring and levels

It's a plain static site with no build step. Open `index.html` in a browser to play locally.
